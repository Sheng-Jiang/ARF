# ARF (AI Relevance Factor) 智能投研平台
## 面向投资人的商业与技术白皮书

---

## 一、 核心痛点与行业背景

生成式AI（Generative AI）掀起的科技浪潮正在重谱全球资本市场。然而，对于专业投资机构与高净值投资者而言，当前面临着三个核心痛点：

1. **静态估值模型失效**：在强烈的“AI叙事”驱动下，相关股票溢价极高。传统估值指标（如静态市盈率 P/E、市净率 P/B）由于无法量化“叙事对估值的扭曲程度”，容易导致投资者陷入两难——要么过早恐高离场，错过成长红利；要么盲目追高，接盘纯概念泡沫股。
2. **产业链复杂且跨国割裂**：AI产业并非单一板块，而是涵盖从能源（L1）、芯片（L2）、算力基础设施（L3）、大模型（L4）到应用软件（L5）的“五层蛋糕”生态。此外，美股（重自由现金流与业绩）与中股（受政策红利、炒作资金、地缘政治影响，且使用“扣非净利润”等独特财务指标）的估值中枢与交易生态存在显著差异，难以用统一尺度进行横向比较。
3. **投研效率遭遇瓶颈**：传统的投研工作流极其依赖人工。分析师需要手动跟踪海量中英文行业动态、编写复杂的 SQL 筛选多因子数据、并在不同的回测软件与绘图工具之间频繁切换，响应市场变化的时效性较差。

---

## 二、 产品定位与核心理念

**ARF 智能投研平台**是专为AI时代打造的**混合量化与大模型 Agent 决策系统**。

平台通过严谨的金融工程量化模型，剥离出股票的 **“AI曝光度”（Exposure）** 与 **“估值拉伸度”（Valuation Stretch）**，合成独创的 **ARF（AI Relevance Factor）指标**，帮助投资者在复杂的AI产业链中，一眼识别出“真金白银的成长标的”与“纯粹资金炒作的泡沫”。

同时，系统引入前沿 of 生成式AI技术（基于 Gemini 大模型），构建了“自然语言智能选股”与“多路并行联网定性归因”两大 Agent 模块，实现投研工作流的智能化与自动化。

## 三、 双引擎架构：量化算法与智能 Agent

ARF 平台的核心优势在于**“严谨的硬核量化计算”**与**“灵活的软性语义理解”**的深度结合。

![ARF双引擎系统架构与数据流向图](reports/architecture_diagram.png)

### 1. 硬核金融量化引擎

#### A. E分（AI 曝光度）：量化产业协同与壁垒
E分综合评估企业在AI变革中的实际受益深度，包含四个维度：
* **产业链层级评分（Layer Score, 30%）**：根据黄仁勋“五层蛋糕”模型进行梯队赋权（应用L5与模型L4赋予100分，算力芯片L2赋予80分，基础设施L3赋予60分，能源L1/绿电赋予40分）。
* **AI纯度（Pure-Play %, 40%）**：由配置文件动态定义的AI相关业务营收与资源占比。
* **供应链话语权（Gross Margin, 20%）**：以毛利率作为供应链核心壁垒的代理指标。
* **前瞻性营收增速（Revenue Growth, 10%）**：引入 200% 的增速上限封顶（例如避免寒武纪等小基数企业的指标畸变），确保模型稳定性。

#### B. V分（估值拉伸度）：三维透视估值偏离
V分不依赖单一乘数，而是通过三维矩阵剖析估值对基本面的偏离程度：
1. **逆向 DCF 模型隐含永久增长率（Implied $g^*$）**：通过求解逆向现金流折现模型，反推当前股价所隐含的、需要企业永久保持的超额增长率。这是衡量市场乐观预期的核心定量指标。
2. **前瞻 PEG 比率**：结合 forward P/E 与 EPS 两年复合年化增速，评估估值与成长性匹配度。
3. **历史 EV/Sales 百分位**：纵向对比股票自身过去 5 年 of 估值中枢。
* **ROE 质量调整**：对企业资产回报率进行评估。高质量回报（如 NVIDIA 超过 100% 的 ROE）可获得估值偏离度扣减（最高20分），而低质量、无现金流支撑的估值拉伸将被加罚。

#### C. ARF 合成与十分位排名
* **合成公式**：$\text{ARF} = \sqrt{\text{E\_score} \times \text{V\_score}}$。采用几何平均数，确保股票必须在“AI敞口高”且“估值偏离大”两个维度同时成立时，才会获得高分。
* **十分位排名**：在“美股腿（US Leg）”与“中股腿（China Leg）”两个完全独立的交易生态内分别进行百分位排序，划分为 D1（最拉伸，风险最高）到 D10（最安全/低估）。
* **泡沫预警旗（Froth Flag ★）**：精准识别市场过热标的。当且仅当满足 $\text{ARF} \in D1$ 且 $\text{ROE} < \text{WACC}$（回报率低于资本成本）且 $\text{P/S} > 25$（估值极度高企）时，系统自动触发泡沫警告。

#### D. 技术面与筹码分布（CYQ）算法
系统每日提取 A 股历史行情，计算 SMA、EMA、MACD、RSI、ATR 等多维度技术指标，并构建**筹码分布（CYQ）模型**，动态测算持仓平均成本、筹码获利比例以及支撑阻力位，为战术择时提供数据支持。

### 2. 智能 Agent 引擎

#### A. 行业首创的自然语言智能多因子选股器（NLP-to-SQL）
传统的选股器需要用户手动设置复杂的筛选滑块，或者编写繁琐的数据库 SQL 代码。ARF 平台内置了基于大模型的自然语言解析器：
* **工作流**：用户直接输入中文或英文的复合投资逻辑，例如 *“均线确认多头排列，且筹码获利盘大于80%”* 或 *“寻找AI曝光度高、基本面优秀且排除泡沫预警的标的”*。
* **技术实现**：大模型自动将语义理解转化为底层的标准 SQL 查询，在 DuckDB 数据库中毫秒级执行，并即时呈现结构化结果。
* **价值**：极大降低了普通投资者和研究员的使用门槛，将选股效率从分钟级提升至秒级。

#### B. 多路并行联网定性归因（Ask Gemini）
量化因子能解决“是什么”的问题，但无法回答新闻舆论与市场情绪带来的“为什么”。
* **工作流**：针对两地市场前五名最拉伸或最具特征的标的，系统自动触发多路并行的 Gemini Agent。
* **智能检索**：Agent 具备语言感知能力。对于美股标的，自动在路透社、彭博社等英文主流财经媒体检索；对于中股（如中际旭创、工业富联），自动使用中文在财新、科创板日报、证券时报等国内权威平台发起检索。
* **归因与对齐（Reconciliation）**：Agent 提取最近 30 天的重大事件（如财报、订单、政策变动），附带可追溯的源网站域名链接（Grounding），并输出一句话对齐分析，解释为何最新的基本面动态会映射为当前的量化分数。

## 四、 核心用户工作流与产品体验

ARF 投研平台提供了一套直观、高效的决策工作流，使用户能够快速完成“宏观研判 -> 风险识别 -> 仓位择时 -> 策略回测”的闭环：

![ARF核心用户工作流与决策闭环图](reports/workflow_diagram.png)

### 终端核心页面亮点展示

1. **全球估值看板（美股 & 中股）**：清晰展示个股在产业链中的层级、ARF得分、十分位、泡沫预警状态以及前瞻市盈率、毛利率等关键财务数据。
2. **泡沫温度计（Bubble Thermometer）**：
   * 采用可视化散点气泡图。
   * **横轴**：E_score（AI敞口，代表未来天花板）。
   * **轴**：V_score（估值拉伸，代表情绪泡沫）。
   * **气泡大小**：企业市值（代表对指数的影响力）。
   * **颜色**：十分位风险度（红色代表高估值偏离度）。
   * 该图让投资人一眼看出哪些是“高硬核高成长”（右下角，如 ROE 极高的 NVIDIA），哪些是“纯概念炒作”（左上角）。
3. **ECharts 机构级 K 线与筹码线**：将 K 线走势与横向筹码分布图合二为一，直观展现资金沉淀区间与筹码套牢盘，提供量化支撑位与阻力位。
4. **Backtrader 策略回测面板**：支持用户自定义回测周期、初始资金、佣金率与交易滑点，运行包括“多因子评分交易策略”在内的多种经典逻辑，输出专业级绩效指标。

## 五, 商业价值与独特优势（UVP）

相比于市场上的传统金融终端（如 Bloomberg、Wind）或单一的 AI 选股软件，ARF 智能投研平台具有独特的商业价值：

| 特性 | 传统金融终端 (Wind/Bloomberg) | 常见 AI 选股软件 | ARF 智能投研平台 |
| :--- | :--- | :--- | :--- |
| **估值维度** | 依赖静态乘数，缺乏叙事溢价量化 | 多为黑盒情绪分析，缺乏基本面公式 | **独创 ARF 双轴模型，量化叙事与基本面的偏离** |
| **产业链对齐** | 分类粗糙，未对齐 AI 核心层级 | 概念关联模糊，无法评估壁垒 | **按 Jensen Huang 5层模型深度对齐并动态赋权** |
| **交互门槛** | 需学习复杂的代码/筛选语法，门槛高 | 仅提供固定推荐，无法自定义筛选逻辑 | **全自然语言（NLP-to-SQL）秒级交互，透明可查** |
| **定性归因** | 新闻与数据割裂，需人工研读归纳 | 生成内容易产生幻觉，无事实对齐 | **大模型并行联网搜索，严格域名 Grounding 与对齐** |
| **回测支持** | 需专业量化团队在本地编写代码运行 | 极少提供，或仅提供简单历史表现 | **内置工业级 Backtrader 框架，一键执行复杂回测** |

### 针对不同客户群体的价值主张：

* **买方基金与家办（Buy-Side & Family Offices）**：
  * **风险防火墙**：通过“泡沫预警旗（Froth Flag）”和“V分”，在组合中有效规避纯概念炒作的垃圾股，降低系统性回撤。
  * **效率增益**：用自动化数据流和 Agent 报告替代初级分析师的日常繁琐工作，缩短决策链条。
* **量化与多策略交易员（Quant Traders）**：
  * 提供干净的 DuckDB 本地多因子快照，方便直接接入自建量化系统。
  * 提供技术指标与筹码分布 API，便于进行高频或波段交易策略开发。
* **高净值个人投资者（HNWIs）**：
  * 极其友好的自然语言交互，无需懂 SQL 或 Python 即可享受专业机构级的量化筛选与定性归因服务。

## 六、 技术壁垒与工程设计

ARF 平台在技术架构上同样具备极高的工程质量与壁垒：

1. **极致性能的分析型存储（DuckDB + Parquet）**：
   平台弃用了沉重的传统关系型数据库，采用 DuckDB 作为核心分析型数据库，支持向量化查询，保障海量多因子数据与历史行情的毫秒级关联分析。快照以标准的 Parquet 列式文件存储，兼顾了高效的版本管理与极佳的跨平台移植性。
2. **高可靠性与可观测性的数据采集管道**：
   数据管道封装了 `yfinance` 与 `AkShare` API，针对跨国网络波动与数据限制，设计了**指数级退避与重试机制（Exponential Backoff with Jitter）**，并在数据库中建立 `fetch_outcomes` 审计表，实现数据采集的可观测性。单个股票的临时缺失会自动降级处理并产生告警日志，绝不中断整体流水线。
3. **可解释、抗幻觉的 AI 架构设计**：
   平台在设计上坚守“严谨可信”的金融底线，拒绝黑盒神经网络预测。大模型（Gemini）仅作为两处**外围辅助组件**：一是**交互翻译官**（将自然语言转化为透明、可审计的标准 SQL 查询），二是**新闻归因员**（通过 Google Search Grounding 提供严格基于事实且带链接的定性解释）。核心的估值模型、财务乘数和技术指标计算全部由底层物理代码执行，彻底消除了大模型常见的“事实幻觉”问题。
4. **云原生与容器化部署**：
   项目提供完整的 Dockerfile 配置，支持作为定时任务（Cloud Build / Kubernetes CronJob）在云端自动运行，每周定期产出 Parquet 快照与 Markdown 报告，实现免维护的自动化流转。
